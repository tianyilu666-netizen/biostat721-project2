# RDU air pollution in 2018 to 2020

BIOSTAT 721 Project 2 by Tianyi Lu, November 11, 2026.

This project cleans daily CO, PM2.5, and ozone measurements from the EPA monitor at RDU airport and explores monthly patterns. The three course-supplied CSV files cover 2018, 2019, and January through April 2020. This is an exposure-data analysis; it does not test an association with sickle cell disease.

## Files

- `data/`: the original course-provided CSV files, unchanged.
- `R/clean_air.R`: the function for cleaning one year and selecting ozone units.
- `Lu_Tianyi_Project2.Rproj`: the RStudio project.
